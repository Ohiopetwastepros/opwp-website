# Onboard a technician

Add one row in [OPWP Operating System → Technicians](https://airtable.com/appcAWPBQB8GmOrcT/tblhWcI09FBRuGERu). Fill in these four fields.

| Field | What to enter |
| --- | --- |
| **Name** | The technician’s display name. Use the same spelling as Sweep & Go so jobs and shifts appear under one name in reports. |
| **SNG Employee ID** | The technician’s numeric employee ID from Sweep & Go. Use one active row per ID. |
| **Status** | Select **Active**. |
| **$/Hr Target** | The approved route revenue target per clocked hour, in dollars. |

Allow up to 10 minutes for a cached lookup to refresh. Find `Unmapped tech ID <id>` in the **Notes** field of the Time & Mileage Log or Daily Job Log when an ID needs review.
